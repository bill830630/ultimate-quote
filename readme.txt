B2B 詢價系統：詢價清單、隱藏價格改詢價按鈕、B2B 會員申請審核、B2B 專屬價／階梯價、後台報價並寄出中文報價單 PDF。

== Description ==

* 詢價清單：顧客可以把多個商品、規格、數量加入詢價清單，一次送出
* 詢價商品：指定商品、分類或全站改成詢價商品，隱藏售價，只有 B2B 會員能加入詢價清單
* B2B 會員：顧客在「我的帳戶」申請，後台審核；B2B 會員在詢價商品看得到 B2B 參考價與數量階梯價，一般商品和其他顧客一樣直接購買
* 後台報價：在詢價單上填單價、運費、稅別、有效期限、付款條件，一鍵產生中文報價單 PDF 並寄給顧客
* 報價單：欄位可開關、拖曳排序、新增自訂欄位；PDF 與 Excel 兩種格式
* 後台開單：電話、LINE、Email 來的詢價可以在後台直接建立報價單
* 折扣：單項打折（幾折）、整單折讓（專案折讓、尾數折讓）
* 附件：顧客詢價時可以上傳圖面、規格書
* 業務窗口：每張詢價單指派負責業務，報價單印業務姓名電話，通知只找負責的人
* 追蹤：報價到期前提醒顧客、過期自動標示、寄出幾天沒回覆通知業務追蹤
* 統編帶入：輸入統一編號自動帶出公司名稱與地址
* 最低訂購量／包裝倍數：數量不合規時自動調整
* 線上確認：顧客可以直接在網站上接受或婉拒報價
* 用 LINE 詢問：商品頁一鍵開啟 LINE 官方帳號聊天室並預填商品資訊
* 通知：Email（可在 WooCommerce 電子郵件設定調整）＋ LINE（搭配「終極登入」外掛）

* 後台可以直接開報價單：「新增報價單」後搜尋商品加入（B2B 會員自動帶 B2B 參考價）、選擇會員自動帶入聯絡資料，儲存時才產生報價單號
* 報價可以打折：每個品項可以填折扣（報價單顯示「9 折」），也可以加整單折讓（固定金額或百分比，例如專案折讓、尾數折讓），在稅前扣除

* 報價追蹤：快到期時自動提醒顧客（Email＋LINE）、過期自動標成「已過期」、寄出幾天顧客沒回覆就整理清單通知管理員和業務
* 詢價單列表多了「業務」欄和篩選，已報價的單會顯示寄出幾天、哪天到期
* 輸入統一編號就自動帶出公司名稱和地址（經濟部商工登記資料，公司、行號都查得到），詢價表單、B2B 申請和後台都能用

* 商品可以設定詢價的最低訂購量和包裝倍數（例如一箱 24 入），加入詢價清單時數量會自動調整並提示顧客
* 修正：商品頁按「用 LINE 詢問」時沒有帶入已選的規格和數量
* 報價單可以印大寫金額（新台幣壹萬貳仟元整）、付款條件、匯款帳號、民國年日期、頁尾文字
* 報價單的欄位可以勾選要不要顯示，也能拖曳調整順序（報價資訊、客戶資料、品項表、總計左側四個區塊分開排）
* 可以新增自訂欄位（例如交貨期、交貨地點、保固），每張報價單分別填寫，也能跟其他欄位一起排序
* 品項表可以加「單位」欄、料號可以獨立成一欄或印在品名下方
* 顧客可以在網站上直接「接受報價」或「婉拒」：Email 和 LINE 的按鈕會打開報價頁，不用登入也能回覆；接受時會留下簽署人姓名，並通知管理員（Email＋LINE）
* 報價過期後顧客就不能再線上接受；重新寄出報價時，顧客可以再回覆一次
* 報價有版本紀錄：改價重新寄出會自動變成「第 2 版」（報價單號、Email 標題都會標示），後台可以看每一版的金額差異和當時的 PDF
* 顧客可以按「再次詢價」，把舊詢價單的商品和數量一鍵放回詢價清單
* 商品頁可以加「用 LINE 詢問」按鈕：填上 LINE 官方帳號 ID 後，顧客一按就會打開聊天室，並預先填好商品名稱、規格、數量和網址
* 詢價清單浮動按鈕改成跟 LINE 按鈕一樣的圓形（右上角顯示數量）；有開「終極登入」的懸浮 LINE 按鈕時，會疊在 LINE 按鈕上方，不再左右各一顆
* 外掛清單改顯示英文名稱「Ultimate Quote」，並拿掉「造訪外掛網站」連結
* 設定頁的分類頁籤改成跟終極電商一樣的文字頁籤，和上方「詢價單／B2B 會員申請／設定」分得出層級
